# Amazon Prime Content Analysis

## Overview

This project is a data analysis case study exploring content trends in the Amazon Prime catalog.

The analysis focuses on the distribution of content by release year, genre dominance, and the number of seasons in TV shows.

The project was created as a data analyst portfolio project using Google Sheets for data cleaning, analysis, and dashboard creation.

## Objectives

The main objectives of this analysis are to:

* Identify content release trends over time.
* Analyze the most frequently appearing genres.
* Examine the distribution of TV shows by number of seasons.
* Present the findings through a visual dashboard.
* Translate the analysis into business-oriented insights.

## Dataset

The dataset used in this project is the **Amazon Prime Movies and TV Shows** dataset from Kaggle.

**Kaggle Dataset:**
[Amazon Prime Movies and TV Shows](https://www.kaggle.com/datasets/shivamb/amazon-prime-movies-and-tv-shows)

* Total records: **9,668 titles**
* Movies: **7,814**
* TV Shows: **1,854**

## Tools Used

* Google Sheets

## Analysis

The analysis covers three main areas:

### 1. Content by Release Year

The analysis examines how the number of titles varies across different release years.

### 2. Genre Dominance

Drama is the most frequently appearing genre with **3,687 occurrences**, followed by Comedy and Action.

### 3. TV Show Seasons

The analysis examines the distribution of TV shows based on the number of seasons.

**1,342 out of 1,854 TV shows (72.38%) have only one season.**

## Key Insights

### Recent Content Concentration

**46.73% of titles were released between 2017 and 2021**, with 2021 recording the highest number at 1,442 titles.

This indicates that recent content represents a major portion of the analyzed catalog and makes release-year segmentation useful for content discovery and catalog analysis.

### Drama Dominates

Drama is the most frequently appearing genre with **3,687 occurrences**, followed by Comedy and Action.

This suggests that genre-based content organization and recommendation could prioritize major genres while still maintaining niche categories for targeted audiences.

### Single-Season Shows Dominate

**72.38% of TV shows have only one season**, with 1,342 out of 1,854 TV shows belonging to the one-season group.

Further analysis using viewing completion, audience engagement, and renewal data could help explain why relatively few shows extend beyond the first season.

## Conclusion

The analysis shows that the Amazon Prime catalog has a strong concentration of recent content, with Drama being the most frequently appearing genre and single-season TV shows representing the majority of TV content.

The findings demonstrate how data cleaning, exploratory analysis, and visualization can be used to identify patterns and generate business-oriented insights from a content dataset.
